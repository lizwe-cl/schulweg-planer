# schulweg-planer
Planung der Schulwegbegleitung in der Nachbarschaft. Es können immer 2 Wochen im Voraus geplant werden.
Es kann für jeden Tag angegeben werden, wer die Kinder begleitet und ob der Weg zu Fuß oder mit dem Auto zurück gelegt wird. 
Für jeden Slot kann mit einem Häkchen rechts oben markiert werden, ob die Begleitung bereits abgestimmt ist.
Optional kann für jeden Tag eine Notiz hinzugefügt werden.
